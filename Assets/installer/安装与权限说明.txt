DingDong 安装与权限说明
Installation and Permissions Guide

一、安装 / Install

1. 把安装盘里的 DingDong 拖到 Applications（应用程序）。
2. 打开“应用程序”文件夹，在 DingDong 上单击右键，选择“打开”。
3. 如果 macOS 仍然阻止打开：进入“系统设置 → 隐私与安全性”，找到 DingDong，选择“仍要打开”。

二、辅助功能权限 / Accessibility

“快速粘贴到上一个应用”和可选的“系统级划词”需要此权限。
普通剪贴板历史与搜索不需要。

1. 打开“系统设置 → 隐私与安全性 → 辅助功能”。
2. 找到 DingDong 并打开开关。
3. 如果列表中没有 DingDong，点击“+”，从“应用程序”中选择 DingDong。
4. 回到 DingDong；如果功能仍未生效，请退出并重新打开应用。

系统级划词默认关闭。安装 1.5.4 或更新版本后，在“设置 → 系统级划词”中开启。
在支持 macOS 选区读取的应用里选中文字，然后点击“复制 / 翻译 / 解释”；
也可按 Option + Command + C 直接复制。复制不需要模型服务。
翻译和解释需要在同一设置区域配置可用的模型服务与所需凭据。
请勿同时运行独立的 DingDong Selection 助手，以免重复响应选区和快捷键。

三、剪贴板访问 / Clipboard Access

如果系统询问是否允许 DingDong 读取或粘贴剪贴板内容，请选择“允许”。
DingDong 的剪贴板历史保存在本机。

四、开机启动 / Launch at Login

如果在 DingDong 设置中打开“开机启动”，macOS 可能要求在
“系统设置 → 通用 → 登录项与扩展”中确认。

不需要的权限

DingDong 不需要“完全磁盘访问权限”或“屏幕录制权限”。
请不要为它开启无关权限。

English summary

Drag DingDong to Applications. On first launch, right-click DingDong and choose Open.
Enable Accessibility if you use Quick Paste or the optional system selection tools.
In version 1.5.4 or later, enable Settings → System selection tools to copy,
translate, or explain selected text. Option + Command + C copies directly.
Copy needs no model service; translation and explanation require your configured service.
Do not run the standalone DingDong Selection helper at the same time.
Allow clipboard access if macOS asks.
Full Disk Access and Screen Recording are not required.

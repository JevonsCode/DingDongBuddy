# DingDong 1.7.0

- Adds local Token history with a daily heatmap, source filters, daily details and CSV export.
- Pairs computers on the same LAN with a six-digit code and reconnects trusted devices automatically.
- Improves phone pairing, QR scanning, browser installation guidance and task notifications.
- Makes first-time Agent setup clearer and adds a read-only list of local Agent plugins.
- Fixes Agent installation paths and clipboard source labels on Windows.
- Refreshes the website with clearer feature descriptions and interactive examples.

# DingDong 1.7.0

- 更新官网功能说明与交互演示。

# DingDong 1.7.0

- Añade un historial local de Tokens con mapa de calor diario, filtros por origen, detalles diarios y exportación CSV.
- Conecta equipos de la misma red local con un código de seis dígitos y reconecta automáticamente los dispositivos de confianza.
- Mejora la vinculación del teléfono, el escaneo QR, la guía de instalación del navegador y las notificaciones de tareas.
- Aclara la configuración inicial de los Agents y añade una lista de solo lectura de sus complementos locales.
- Corrige las rutas de instalación de Agents y las etiquetas de origen del portapapeles en Windows.
- Actualiza el sitio web con descripciones más claras y ejemplos interactivos.

# DingDong 1.11.1

- Shows Library resources as separate cards, tinted by type, instead of one divided list.
- Animates the Windows tray reminder popup and shows it only when there are two or more reminder groups.
- Keeps device-link messages flowing when a phone leaves a stale relay connection behind.
- Shares the device-link wire format with the upcoming Android companion app.
- Refreshes the website with a scroll-through product tour, the real Connected devices screens, a full shortcut sheet, and current settings, tools, and Agent lists.

# DingDong 1.11.1

- 资源库改为按类型着色的独立卡片，不再是一整块分隔列表。
- Windows 托盘提醒浮层加入动画，且只在有两组及以上提醒时显示。
- 手机留下旧的中继连接时，设备连接消息仍能正常送达。
- 设备连接的通信格式与即将推出的 Android 伴侣应用共用。
- 官网更新：滚动演示产品流程，使用真实的连接设备界面，新增完整快捷键一览，并更新设置、工具和 Agent 列表。

# DingDong 1.11.0

- Detects local Agents and guides DingDong setup, updates, and per-Agent cleanup with a preview of the affected configuration.
- Adds a skippable first-install Agent connection guide and shares connection management with Resource Manager.
- Remembers opened notifications through the right-hand icon color and adds a “Last seen here” divider between new and earlier events.
- Renames Resource Manager’s Agent history to Recent notifications and uses the same star icons as the quick panel.
- Widens Settings, adds section navigation with consistent heading alignment, and marks Notifications (Sounds) with the DingDong bell-ringing character.
- Simplifies the macOS notch option to a switch for revealing notifications from the left.
- Fixes clipboard changes being missed when another copy arrives during an asynchronous capture.
- Updates Agent integration and conversation opening; MCP Agent reminders now require a conversation ID.
- Uses system screenshot tools on macOS and Windows and removes the in-app screenshot editor.
- Uses the DingDong product name consistently across localized interfaces and documentation.

# DingDong 1.11.0

- 自动检测本机 Agent，引导安装、更新和按 Agent 清理 DingDong 接入配置，并在操作前预览受影响的配置。
- 新增可跳过的首次安装 Agent 接入引导，资源管理与 Agent 连接使用同一套接入管理。
- 通过右侧打开图标的颜色记录已打开的通知，并以“上次看到这里”分割本次新增和以前的消息。
- 资源管理中的 Agent 历史改为“最近通知”，图标与唤出面板统一使用星星样式。
- 加宽设置窗口，新增分区目录并修正标题定位；“通知（声音）”加入 DingDong 摇铃铛 IP 形象。
- macOS 刘海选项简化为开关，开启后从刘海左侧显示通知。
- 修复异步采集中再次复制时，新剪贴板内容可能未被记录的问题。
- 更新 Agent 接入与会话打开组件；通过 MCP 发送 Agent 提醒时必须提供会话 ID。
- macOS 与 Windows 截图改用系统截图工具，移除应用内截图编辑器。
- 各语言界面及文档统一使用 DingDong 产品名称。

# DingDong 1.11.0

- Detecta Agents locales y guía la instalación, actualización y limpieza de la configuración de DingDong por Agent, con una vista previa de los cambios.
- Añade una guía inicial de conexión que se puede omitir y comparte la gestión de conexiones con el gestor de recursos.
- Recuerda las notificaciones abiertas con el color del icono derecho y separa los eventos nuevos y anteriores con “Última visita”.
- Renombra el historial de Agents del gestor de recursos a Notificaciones recientes y usa las mismas estrellas que el panel rápido.
- Amplía Ajustes, añade un índice con títulos alineados y destaca Notificaciones (sonidos) con el personaje de DingDong tocando la campana.
- Simplifica la opción del notch de macOS a un interruptor para mostrar las notificaciones desde la izquierda.
- Corrige la pérdida de cambios del portapapeles cuando llega otra copia durante una captura asíncrona.
- Actualiza la integración de Agents y la apertura de conversaciones; los avisos de Agents por MCP requieren un ID de conversación.
- Usa las herramientas de captura del sistema en macOS y Windows y elimina el editor de capturas de la aplicación.
- Unifica el nombre DingDong en las interfaces localizadas y en la documentación.

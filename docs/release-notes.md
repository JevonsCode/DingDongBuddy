# DingDong 1.9.1

- Simplifies AI+ to on-demand Prompt, Skill and MCP selection for Agents; removes insights, suggestions, automatic analysis and check-ins.
- Accepts the model token directly in local settings, with paste and show/hide controls; re-enter tokens previously saved in Keychain.
- Improves resource-selection timeouts and keeps local matching available when the model cannot respond.
- Fixes popup dismissal and paste focus, adds space beside resource actions, and keeps rear menu-bar reminder bubbles steady.

# DingDong 1.9.1 正式版

- AI+ 精简为按任务为 Agent 选择 Prompt、Skill 和 MCP，移除洞察、建议、自动分析与主动关怀。
- 模型 Token 改为直接输入并保存在本地设置，支持粘贴和显示/隐藏；原先存入密钥库的 Token 需重新输入。
- 调整资源筛选超时，模型无法响应时继续使用本地匹配。
- 修复弹窗收起与粘贴焦点，增加资源操作按钮的边缘留白，后排菜单栏提醒气泡保持静止。

# DingDong 1.9.1

- Simplifica AI+ a la selección de Prompts, Skills y MCP bajo demanda para los Agents; elimina información, sugerencias, análisis automáticos y recordatorios de bienestar.
- Permite introducir el token del modelo en los ajustes locales, con controles para pegarlo y mostrarlo u ocultarlo; los tokens guardados antes en Keychain deben introducirse de nuevo.
- Ajusta el tiempo de espera de la selección de recursos y conserva la selección local si el modelo no responde.
- Corrige el cierre de ventanas y el foco al pegar, añade margen a las acciones de recursos y mantiene estables las burbujas secundarias de avisos.

# Community voices

The public catalog is backed by open Issues in `JevonsCode/dingdong-voices`. Both the website and desktop app accept the same submission fields: `Description`, `Audio`, `License`, `Source`, and a checked `Rights confirmation`. An open submission is not a guarantee that the uploader has the rights they claim. The website keeps the full attribution and license available in the details dialog; the installation dialog shows them before confirmation.

The audio URL must be either a GitHub user attachment or an exact WAV path in this repository pinned to a 40-character commit. Arbitrary hosts, credentials, non-HTTPS URLs and untrusted redirects are rejected. Audio is limited to 5 MiB, mono or stereo PCM WAV and at most three seconds. The desktop app re-fetches the Issue before and after the download, rejects changed metadata, and records SHA-256 hashes and attribution with the installed local copy. It does not use a moderator label or an owner approval comment. Existing local custom imports keep their separate limits.

The website's normal install action opens `dingdong://voice/<issue-number>` for the release app. The explicit `?app=dev` preview uses `dingdong-dev://voice/<issue-number>` for the Debug app, so the two registrations do not compete. On macOS the application validates that the link contains only a positive, bounded Issue number, opens Settings at the notification section, and presents the matching submission. No installation or reminder setting changes occur until the user confirms. A confirmed installation adds the sound to the local reminder picker without changing any active reminder. The dialog may preview a validated temporary copy; cancelling closes it without adding the sound. Copying a submission link and looking it up in Settings remains available on older versions and platforms without a registered handler, including Windows. The website's download action validates and downloads a WAV independently.

For an isolated macOS preview, build Debug with `--dart-define=DINGDONG_PREVIEW_SANDBOX=true`; this prevents the preview from synchronizing resources into real Agent configurations and disables automatic clipboard monitoring during the preview. The catalog uses unauthenticated GitHub requests. Lists are cached in memory for five minutes; imports always re-read the live Issue and have bounded size, redirect count and timeouts. Removing an installed library entry does not delete files currently used by reminders. The voice website is maintained and published by `JevonsCode/dingdong-voices`; the older DingDong website addresses redirect there while retaining query parameters.

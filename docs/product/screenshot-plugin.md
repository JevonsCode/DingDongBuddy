# 截图插件与插件详情

本说明对应 DingDong 1.10.2 的 Windows 截图与划词插件。

在“资源管理 → 插件”中，点击插件名称或整行即可打开详情，使用返回按钮回到列表。
Jev 保留原有配置；Windows 划词可在详情中启用并配置模型。

一级“插件”只管理叮咚自己的功能扩展。Codex、Claude Code 等客户端的插件
清单移到“资源 → Agent 插件”（窄窗口通过资源操作菜单进入）。此入口目前按需
读取本机插件名称、来源和配置启用状态，不提供安装、卸载或配置管理。

## Windows 截图

1. 打开“截图”详情，启用插件。默认全局快捷键为 **Ctrl+Alt+A**。
2. 点击快捷键按钮，再按自己的组合键；可恢复截图默认值。与叮咚现有快捷键
   重复，或被系统/其他程序占用时，显示冲突并保留原配置。
3. 用快捷键或“立即截图”冻结当前桌面，拖动框选区域。
4. 松开鼠标后进入钉东编辑窗口，添加箭头、矩形、椭圆、画笔、文字、马赛克
   或模糊，也可撤销和重做。
5. 点击“复制”复制图片，或点击“保存”选择 PNG 保存位置；关闭编辑窗口取消。

复制/保存失败会在截图浮层提示，可重试或取消。取消保存对话框会返回编辑。
关闭插件会释放快捷键并关闭正在编辑的截图。叮咚退出后快捷键不再生效。

截图覆盖 Windows 虚拟桌面，保留物理像素尺寸。不同屏幕之间没有显示器覆盖的
空白区域显示为黑色。未实现飞书的滚动长截图、OCR 或贴图。
macOS/Linux 详情会明确提示截图暂未支持。

截图只在内存中处理，不联网，不自动保存。主动复制后，系统剪贴板会收到图片，
叮咚的剪贴板历史是否收录由现有剪贴板监控设置决定。取消后释放截图内存。
配置用一个独立偏好键保存，由主程序串行处理；详情窗口不单独注册快捷键。

## Windows 划词

此前 Windows 无法划词的原因是仅 macOS 接入了原生选区监听和浮层；配置模型
无法补上缺失的平台实现。本次补齐 Windows UI Automation 取词、原生触发监听、
钉东浮条和模型结果面板。开源来源及适配范围见 [嵌入式组件说明](embedded-plugin-sources.md)。

在详情启用后，支持的程序内选择文字可显示复制、翻译、解释、润色浮条。
仅点击模型动作或追问才发送文字；自动读取不模拟复制，不修改剪贴板。
密码框、无法读取选区的程序不弹浮条。Token 使用系统安全存储，子窗口不接收密钥。
自动化测试覆盖请求取消、延迟结果、停用、坐标换算及模型协议；真实跨应用兼容性、
多屏高 DPI 和实际模型服务仍需人工验收。

## 验证

```powershell
flutter analyze
flutter test test/features/screenshot test/features/selection test/features/jev test/features/agent_plugins test/features/settings/workspace_shortcuts_test.dart
powershell -File scripts/test_screenshot_native.ps1 -FlutterRoot <Flutter SDK 根目录>
```

原生截图测试显示临时测试画面，验证捕获、PNG 裁剪像素、快捷键与编辑生命周期。
Flutter 测试验证标注、撤销/重做、物理像素导出和取消保存。
`scripts/test_windows_selection_native.ps1` 验证原生取词的取消及生命周期；
如果系统拒绝前台焦点，真实控件测试会明确跳过，不算作兼容性通过。

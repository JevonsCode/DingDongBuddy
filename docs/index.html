How it works

A few everyday conveniences

Saved on your computer

Clipboard content and resources stay local by default. Agent access to clipboard content starts off; you choose what to share with paired devices.

Skills open when needed

For dynamic Skills, the Agent sees a name and description first, then loads the instructions when needed. Matching Prompts are delivered at task start.

Open it with a shortcut

Use a shortcut to search and classify copied content, preview before reuse, and pin saved items you need often.

Keep one resource library

Add Prompts, Skills, and MCP servers, then choose which projects or Agents can use them.

Send it to your phone

Pair a device to transfer files and clipboard items, or receive Agent reminders away from your computer.

Ask your Agent to set it up

Tell your Agent which resource to add or change and which project needs it. DingDong checks and saves the configuration.

Check Agent alerts in one place

Codex already has completion notifications. DingDong gathers connected-Agent events with unread history and the sound you choose; each client's own alert settings still apply.

Connected devices · Multiple computers

Check several computers from one phone.

Scan each computer's QR code to pair it. You can see which computers are online and switch the active one. Files, clipboard items, and reminders stay grouped by their source computer.

Keep the source computer connected

Verified local connections have no file-size limit. Other routes keep the 25 MB limit. Follow progress on desktop or mobile, and pause or resume while both apps stay open.

On the same local network, DingDong tries a direct WebRTC connection first. Otherwise it uses an end-to-end encrypted relay. Android can use the web app without installing it. On iPhone and iPad, add it to the Home Screen to enable push notifications. Tap the tabs or swipe between them on mobile; a notification opens Agent reminders. What you can ask your Agent

Enable the resources and choose where they apply first. Then ask in your own words.

Prompt

“Review this page against our project’s UI rules and fix the problems.”

The project Prompt is applied automatically before the Agent starts.

Skill

“Use this project’s release workflow, run every check, and prepare the next release.”

The Agent matches the Skill description, then loads its full workflow and files.

MCP

“Use my GitHub tools to find why the latest main workflow failed.”

The configured MCP is available, and its tools are called only when needed.

Connect an Agent

For a client that supports MCP, add the matching snippet to its settings. The examples below use the macOS installation path.

  • Install DingDong in /Applications.
  • Point the Agent at DingDong's built-in MCP command.
  • Manage the shared resources in DingDong.
{
  "mcpServers": {
    "dingdong": {
      "command": "/Applications/DingDong.app/Contents/MCP/bundle/bin/dingdong_mcp"
    }
  }
}
[mcp_servers.dingdong]
command = "/Applications/DingDong.app/Contents/MCP/bundle/bin/dingdong_mcp"

What it does for you

Find what you copied
Press ⌘⇧V (Ctrl+Shift+V on Windows), filter by links, images, files, or text, preview, then press Return to use it. Pin the things you reuse.
One library for every Agent
Add Prompts, Skills, and MCP servers once, then choose which projects or Agents get each one. You can also ask your Agent to add or change them for you.
Know which reminder it is by ear
Finished, stuck, or waiting on a decision: give each kind its own sound and color, or set a one-time reminder for the next task. A “Last seen here” line separates new events from ones you’ve read.
Connects to the Agents you already use
On first launch, DingDong finds the Agents on this computer and connects them. Updates and removals show the exact configuration changes before anything is written.
Take it to your phone
Pair your phone to receive Agent reminders and to send files and clipboard items between devices. Connections go direct when possible; the relay is end-to-end encrypted.
Stays on your computer
Clipboard history and resources are stored locally. Agents can’t read clipboard content until you turn that on in Settings.

What you can ask your Agent

Enable the resources and choose where they apply first. Then ask in your own words.

Prompt

“Review this page against our project’s UI rules and fix the problems.”

The project Prompt is applied automatically before the Agent starts.

Skill

“Use this project’s release workflow, run every check, and prepare the next release.”

The Agent matches the Skill description, then loads its full workflow and files.

MCP

“Use my GitHub tools to find why the latest main workflow failed.”

The configured MCP is available, and its tools are called only when needed.

When a day is incomplete, its total is shown as a minimum with ≥. Days with no usable data show as unknown instead of a made-up zero.

Saved on this computer

Store counts, not conversations.

Only numeric totals are saved, on this computer, without any chat text. They are never sent with the anonymous install statistics. Token counts measure usage, not cost.

Prefer manual setup?

For a client that supports MCP, add the matching snippet to its settings. The examples below use the macOS installation path.

  • Install DingDong in /Applications.
  • Point the Agent at DingDong's built-in MCP command.
  • Manage the shared resources in DingDong.
{
  "mcpServers": {
    "dingdong": {
      "command": "/Applications/DingDong.app/Contents/MCP/bundle/bin/dingdong_mcp"
    }
  }
}
[mcp_servers.dingdong]
command = "/Applications/DingDong.app/Contents/MCP/bundle/bin/dingdong_mcp"
